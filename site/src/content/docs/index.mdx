## One-line install

No pre-installed Python, `uv`, or `git` required. Installs HORUS, fetches SITL & vision models, and starts **HORUS Studio** automatically (set `HORUS_NO_START=1` to skip auto-launch):

<Tabs syncKey="os">
  <TabItem label="Windows (PowerShell)">
    ```powershell
    irm https://horus-drone.github.io/horus/install.ps1 | iex
    ```
  </TabItem>
  <TabItem label="Linux / macOS">
    ```sh
    curl -LsSf https://horus-drone.github.io/horus/install.sh | sh
    ```
  </TabItem>
</Tabs>

## Development install (from a local clone)

Clone the repository, then pick your OS and expand `uv` (recommended) or `pip`:

<Tabs syncKey="os">
  <TabItem label="Windows (PowerShell)">
    <details>
    <summary>With uv (recommended)</summary>

    Requires [`uv`](https://docs.astral.sh/uv/getting-started/installation/). Creates `.venv` with `horus-drone` in editable mode and `pytest` ready to run:
    ```powershell
    uv sync --python 3.12
    uv run horus
    ```
    Or activate `.venv` once to run `horus` and `pytest` directly:
    ```powershell
    .\.venv\Scripts\Activate.ps1
    horus
    ```

    </details>

    <details>
    <summary>With pip (Python 3.10–3.13)</summary>

    ```powershell
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -e .
    horus
    ```

    </details>
  </TabItem>
  <TabItem label="Linux / macOS">
    <details>
    <summary>With uv (recommended)</summary>

    Requires [`uv`](https://docs.astral.sh/uv/getting-started/installation/). Creates `.venv` with `horus-drone` in editable mode and `pytest` ready to run:
    ```sh
    uv sync --python 3.12
    uv run horus
    ```
    Or activate `.venv` once to run `horus` and `pytest` directly:
    ```sh
    source .venv/bin/activate
    horus
    ```

    </details>

    <details>
    <summary>With pip (Python 3.10–3.13)</summary>

    ```sh
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -e .
    horus
    ```

    </details>
  </TabItem>
</Tabs>

When running from a local clone, `horus` automatically fetches missing SITL and ONNX models on first launch.

## Why HORUS?

<CardGrid stagger>
  <Card title="Deterministic Safety" icon="approve-check-circle">
    ArduPilot owns flight stability, 7-beam ToF proximity avoidance, and hardware RC takeover (`PILOT`). Operator **HOLD / LAND / HOME** interrupts the AI immediately and locks out AI flight tools.
  </Card>
  <Card title="Latency-Tolerant Supervision" icon="rocket">
    The cloud **AI model** picks one base move at a time while onboard **Camera vision** tracks numbered targets and compensates for radio RTT. If the AI goes quiet, the drone holds and returns home.
  </Card>
  <Card title="Zero-Setup 3D World" icon="laptop">
    Built-in Python/MuJoCo **Test world** runs real ArduCopter 4.7.1 SITL (`--model JSON`) natively on Linux and Windows, with no Docker, Gazebo, or GStreamer required.
  </Card>
  <Card title="Bench to Field" icon="setting">
    Connect USB/telemetry radios, companion computers (`horus mcp`), Gazebo Harmonic, GTA V, or the installable phone **Control app** over Tailscale.
  </Card>
</CardGrid>
